# بَيْت | בַּיִת — من اللقاء العابر إلى الشراكة المستدامة

منصة رقمية وتربوية ذكية تجمع المدارس العربية واليهودية المتقاربة جغرافياً وفكرياً في حيز آمن ومتساوٍ، للانتقال من مفهوم **"الضيف والمضيف | אורח ומארח"** إلى مفهوم **"أصحاب البيت الواحد | שותפים לבית אחד"**.

---

## 🌟 أقسام المنصة الرئيسية

1. **الصفحة الرئيسية (Landing Page):**
   - الرؤية التربوية والأهداف الخمسة للمشروع.
   - مسار العمل خطوة بخطوة وإحصائيات المنصة الحية.
   - تبديل فوري للغة العرض بالكامل (**عربي ↔ עברית**).

2. **نظام التسجيل والمطابقة الذكية واليدوية (Matching & Registration Portal):**
   - تسجيل المدارس وتحديد المرحلة العمرية، الاهتمامات المشتركة، ونوع النشاط المفضل.
   - **خوارزمية الملاءمة الذكية (AI Matching):** ترتيب المدارس المقترحة للتوأمة حسب المسافة الجغرافية (كم)، المرحلة العمرية، والاهتمامات المشتركة.
   - **الاختيار اليدوي وتمييز المدارس غير المقترنة (`لم تقترن بعد • טרם שודך`):** إمكانية الفرز اليدوي حسب خصائص المدرسة وإظهار المدارس المتاحة للتوأمة الفورية.
   - إنشاء الغرفة المشتركة وتوليد رمز دخول خاص للطلاب عند موافقة الطرفين.

3. **مساحة الطلاب والتعلم المشترك (Students & Shared Learning Space):**
   - دخول آمن للطلاب باستخدام رمز الصف المشترك (مثل `BAYT-2026` أو `GALIL-101`) بدون الحاجة لبيانات شخصية حساسة.
   - **المنتدى التفاعلي "نتحدث معاً | מדברים יחד":** مزود بميزة **الترجمة الفورية الذكية** بين العربية والعبرية بضغطة زر.
   - **مختبر البحث والعمل المشترك:** مشاركة المعطيات الميدانية، لوحة العمل التعاوني (Padlet / Canvas)، والمرشد البحثي الذكي (AI Research Mentor).
   - **جدار الإنجازات المشترك (Shared Wall):** معرض رقمي للمشاريع المنجزة.

---

## 🚀 طريقة التشغيل محلياً (Local Setup)

يتطلب المشروع **Node.js (الإصدار 22.5 أو أحدث، مثل Node v24)** حيث يستخدم قاعدة بيانات SQLite المدمجة (`node:sqlite`).

```bash
npm install
npm start
```

ثم افتح المتصفح على الرابط:
`http://localhost:3000`
